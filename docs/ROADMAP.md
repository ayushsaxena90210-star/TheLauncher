# Roadmap

## Phase 1 — Runnable foundation

Electron, React, FastAPI, Tailwind, routing, base Hydra-inspired theme, and a verified local health connection. No library functionality.

## Phase 2 — Persistence foundation

SQLite, SQLAlchemy models, migrations, API structure, and basic CRUD contracts.

## Phase 3 — Game library

Manual game management, cards, search, filtering, and empty/loading/error states.

## Phase 4 — Launching and play sessions

Typed Electron IPC for executable launch, session tracking, and recently played games.

## Phase 5 — Folder scanner

Recursive scans, exclusions, executable detection, review/import flow, and progress reporting.

## Phase 6 — Metadata and artwork

Provider integration, metadata matching, locally cached covers, and retry/error handling.

## Phase 7 — Statistics

Playtime summaries, recently played, most played, and library insights.

## Phase 8 — Settings

Theme preferences, scan roots, API key, cache management, and local settings persistence.

## Phase 9 — UI polish

Keyboard flow, responsiveness, animation, accessibility, and refined loading/error states.

## Phase 10 — Packaging

electron-builder configuration, icons, installer validation, and release build documentation.
